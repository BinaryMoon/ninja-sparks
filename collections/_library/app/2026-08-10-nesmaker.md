NESmaker is a game development tool designed to make creating games for the original Nintendo Entertainment System more accessible.

Instead of starting from scratch with 6502 assembly language, NESmaker provides tools for building graphics, levels and gameplay while handling much of the complicated technical work behind the scenes. The finished games are real NES games, so they can run in an emulator or on original hardware.

What I particularly like about NESmaker is that you're still working within the limitations of the NES. You have modern tools to make development easier, but you're creating something for hardware designed in the 1980s.

NESmaker is now being succeeded by RetroGameForge, a new and more ambitious game development tool designed to support the NES and other platforms.
