Twine is a free, open-source tool for making interactive stories and text-based games. You create your story by connecting passages together, letting readers make choices that send them down different paths. It works particularly well for choose-your-own-adventure stories, but people have used it for everything from small experimental games to interactive fiction and educational projects.

You don't need to know how to code to get started. However, Twine outputs standard HTML, so there's plenty of scope to customise your project with HTML, CSS and JavaScript if you want to dig deeper. You can use Twine in your browser or download the desktop app, and finished stories can be published online as ordinary web pages.
