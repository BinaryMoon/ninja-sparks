Retro Puzzle Maker is a free browser-based tool for creating puzzle games that run on the original Nintendo Entertainment System (NES).

It provides visual tools for designing graphics, levels and gameplay without requiring you to learn how to program the NES from scratch. You can test your game directly in the browser using the built-in emulator, share it online, or export it as a real NES ROM that can run in other emulators or on original hardware.

The thing I particularly like about Retro Puzzle Maker is how deliberately limited it is. Rather than trying to let you create any kind of game, it concentrates specifically on puzzle games. That gives you a small set of tools and rules to work with, leaving you to concentrate on what you can create within those constraints.

It's a great little tool for experimenting with game development, especially if you like retro games and want to make something without setting up an entire development environment first.
